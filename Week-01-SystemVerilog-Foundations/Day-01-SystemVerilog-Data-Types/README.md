# Day 01 – SystemVerilog Data Types

## Topics Covered
- 2-state vs 4-state data types
- `logic` vs `reg`
- `bit`, `byte`, `shortint`, `int`, `longint`
- `integer` and `time`
- Signed vs unsigned
- Implicit & explicit casting
- X and Z states
- Data sizing, truncation & extension

## Practical Work
Implemented and tested SystemVerilog programs on EDA Playground for:
- Data type comparison
- Signed/unsigned operations
- X/Z behavior
- Type casting
- Sizing and extension

## Day 1 Outcome
Built a basic understanding of SystemVerilog's **data types, width, signedness, and 2/4-state behavior**.
